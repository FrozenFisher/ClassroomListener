# 课程表显示程序

这是一个使用PyQt6开发的课程表显示程序，可以读取Excel格式的课程表并实时显示当天的课程安排。

## 功能特点

- 自动识别当前是星期几并显示对应的课程表
- 实时显示当前时间
- 自动高亮显示下一节课程
- 支持Excel格式的课程表导入

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用说明

1. 准备课程表Excel文件，格式要求：
   - 默认从程序所在目录下的schedule.xlsx读取
   - 也可以通过界面上的"选择课程表文件"按钮选择其他Excel文件
   - 支持.xlsx和.xls格式
   - A1单元格：周一
   - A2-A12：周一的课程时间
   - B2-B12：周一的课程内容
   - C1：周二
   - C2-C12：周二的课程时间
   - D2-D12：周二的课程内容
   - 以此类推...

2. 运行程序：
```bash
python schedule_display.py
```

3. 在程序启动后，点击"选择课程表文件"按钮，选择你的课程表Excel文件。

## 打包为exe

如果你想将程序打包为可执行文件（exe），请按照以下步骤操作：

1. 确保已安装所有依赖：
```bash
pip install -r requirements.txt
```

2. 运行打包脚本：
```bash
python build_exe.py
```

打包完成后，你可以在`dist`目录下找到生成的exe文件。

注意事项：
- 确保`schedule.xlsx`文件与exe文件在同一目录下
- 首次运行可能需要等待几秒钟程序启动
- 如果遇到缺少DLL文件的错误，请确保系统已安装最新的Visual C++ Redistributable

## Excel文件格式示例

| 周一 | 课程 | 周二 | 课程 | ...
|------|------|------|------|----
| 8:00-8:45 | 语文 | 8:00-8:45 | 数学 | ...
| 9:00-9:45 | 数学 | 9:00-9:45 | 英语 | ...
| ...  | ...  | ...  | ...  | ...

注意：时间格式应为"HH:MM-HH:MM"（例如"18:00-19:00"）
